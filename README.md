자동차 경주
==============
***
> ## 프로젝트 개요
> > 사용자로부터 자동차 이름들과 시도할 횟수를 입력받아 각각의 자동차들이 시도할 횟수만큼 경기를 치루는 프로그램
***
구현 해야하는 기능
----
+ 자동차 이름을 입력 받는 기능
+ 시도할 횟수를 입력 받는 기능
+ 각 자동차의 무작위 값이 4이상일 때, 한 칸 이동하는 기능 (한 번의 게임)
+ 한 번의 게임을 시도할 횟수만큼 반복하는 기능
+ 반복 완료 후 각 자동차들의 이동거리를 비교해 우승자를 찾는 기능
***
기능 요구 사항 분석
---
* **입력 요구 사항** 
  + 자동차 이름은 쉼표(",")로 구분하며, 입력 되는 자동차 대수는 제한이 없다.
  + 자동차 이름은 5자 이하로 제한한다.
  + 시도할 횟수는 1 이상의 자연수만 가능하다.(변수를 int로 설정하였으므로 int 범위 내의 자연수만 가능)

* **출력 요구 사항**
    + [실행 결과] 메세지를 출력한다. 
    + 한 번의 게임을 실행한다.
    + 한 번의 게임을 입력 받은 시도할 횟수 n번만큼 반복한다.
    + 우승자를 출력한다. 공동 우승자가 있는 경우 쉼표(",")로 구분하여 출력한다. (ex. pobi, jun)
***
예외 처리
---
+ 자동차 이름이 6자 이상 입력될 경우 예외 발생
+ 시도할 횟수가 1이상의 자연수가 아닐 시 예외 발생
+ 자동차 이름 또는 시도할 횟수가 공백 입력시 예외 발생
***
